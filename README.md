# Racing Futures Prices

**[Download the latest spreadsheet](https://raw.githubusercontent.com/powpow1010/futures-prices/main/futures_prices_latest.xlsx)**

Futures (ante-post) fixed win odds for gallops, harness and greyhounds from
TAB, Ladbrokes and Sportsbet, matched race-by-race and runner-by-runner,
with per-book prices, 3-book average and best price.

## How fresh is this file?

It is **updated manually, not on a schedule** — the prices are from whenever
the last pull was run, which may be hours or days ago.

**Always check the `Generated` timestamp on the About sheet** before using
these prices.
